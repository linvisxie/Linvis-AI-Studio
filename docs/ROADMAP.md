## P0 — 补齐 V1.0 的验证缺口（建议最优先）

这些不是新功能，而是**把已写好的东西验证到底**。

### 1. Codex 真实会话验证

- 在 Codex 中打开本目录
- 确认它读到 `AGENTS.md`（直接问"铁律第 2 条是什么"）
- 让它执行 `doctor` → 改一个镜头 → `render`
- 通过后把 AGENTS.md 中 Codex 状态改为「已实测」

### 2. DSH 真实 Skill 加载验证

- 在 DSH 0.2.1-rc.5 中确认 `.dsh/skills/` 是否被扫描
- 若不被扫描，改为 DSH 实际支持的路径（不改 DSH 内核，只加适配文件）
- 通过后更新状态

### 3. 真人中文配音 + 中文字幕

这是当前最大的功能空白。已有管线只是用英文占位音频验证过。

需要：
- 一段真人中文配音（wav，任意长度）
- 验证 openai-whisper `base` 中文识别准确率
- 若不够好，测试 `small` / `medium`（需联网下载，或用 faster-whisper 的完整快照）
- 验证词级时间戳在中文长句上的对齐质量

### 4. faster-whisper 模型补全

当前 `.venv` 里的 faster-whisper 装了但模型快照缺 `model.bin`。

- 联网时执行一次 `WhisperModel('small')` 让它下载完整快照
- 或用 `--model-dir` 指向手动放置的 CTranslate2 模型目录
- 补全后转写速度可提升 2–4 倍

### 5. 图片镜头验证

`image-scene` 已实现但 EP01 未使用图片。需要：
- 至少一张真实图片跑通 Ken Burns + 转场
- 验证 `_project` 素材复制机制在图片上的表现

## P1 — 提升成片质量

### 6. 转场系统升级

当前只有 fade / wipe / zoom / 黑场。建议：
- 用 `@remotion/transitions`（已安装）接入正式转场
- 加：crossfade、slide、flip、clock-wipe、film-burn
- 支持转场时长与缓动曲线在 `project.json` 里配置

### 7. 动画参数外置

现在缓动曲线、弹簧参数写死在 `video/scenes/*.tsx` 里。建议：
- 在 `props` 里开放 `easing` / `spring` / `delay` / `duration` 字段
- 这样改动画手感不需要改代码

### 8. 音频能力增强

- 音频波形可视化（配合 BGM 做节奏可视化）
- 多轨独立音量自动化曲线（现在只有 fadeIn/fadeOut）
- 侧链压缩（配音说话时 BGM 自动压低）——这是口播视频的刚需
- 更多生成器：弦乐铺底、低频扫频、金属撞击、环境雨声

### 9. 字幕样式系统

- 预设样式：抖音黄字、极简白字、关键词描边、双行滚动
- 关键词自动加粗/变色（基于词重要性）
- 字幕安全区适配（避开平台 UI 遮挡）

## P2 — 扩展制作能力

### 10. 竖屏模板库

把 EP01 的镜头组合抽成可复用"模板"：
- `trailer-open`（预告片开场，本次做的）
- `list-reveal`（清单揭示）
- `quote-card`（金句卡）
- `data-viz`（数据可视化口播）
- `before-after`（对比）

模板 = 预置的 `scenes[]` 结构 + 配方，`linvis init --template trailer-open` 直接用。

### 11. 长视频分段渲染

当前 9.5s 视频约 33s 渲染（3.5x 实时）。10 分钟视频会到 35 分钟。

建议：
- 按镜头分段并行渲染，最后 FFmpeg 拼接
- 引入帧级缓存（改了哪个镜头只重渲那个）
- 这一步做完才能真正支撑"完整第一期视频"

### 12. 素材库管理

- `assets/library/` 集中存放常用图片/图标/字体
- `linvis assets list` 查看可用素材
- 自动登记许可信息

### 13. 多语言字幕

- 一份配音生成多语言字幕
- 字幕轨切换

## 距"能制作完整第一期视频"还差什么

按优先级排列：

1. **真人配音 + 中文字幕验证**（P0-3）
   — 没有这一条，口播视频的核心链路就没打通

2. **侧链压缩**（P1-8）
   — 口播视频里 BGM 压不住人声会很难听，这是硬需求

3. **段落模板库**（P2-10）
   — 第一期视频不会只有开场，需要多种段落结构

4. **长视频分段渲染**（P2-11）
   — 5–10 分钟视频的渲染时间必须先解决，否则迭代太慢

5. **转场与动画参数外置**（P1-6、P1-7）
   — 精修阶段会频繁调手感，不能每次都改代码

6. **图片/素材生产流程**（P0-5、P2-12）
   — AI 生成的图片、截图、图表如何进入工程，目前只有机制没有流程

**结论**：V1.0 的"引擎骨架 + 开场样片"是完整可用的。但从"能渲染 10 秒开场"
到"能稳定产出 8 分钟成片"，还差上述 6 项，其中第 1 项最关键。
